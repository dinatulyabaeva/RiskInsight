# Отчет о проверке RiskInsight 1.0.0

Дата: 21 октября 2026. Это отчет о фактически выполненных локальных проверках, а не сертификат промышленной готовности.

## Расчетная проверка

Маленький fixture задает ожидаемые значения независимо от генератора: остаток 9600 ₽, остаток DPD90+ 5800 ₽, учебный EL 1846 ₽. Сверяются доли по остатку и количеству, взвешенная ставка, полное разбиение по корзинам и согласованность разложения изменения по трем измерениям.

В первом прогоне обнаружилась погрешность из-за округления промежуточных долей при разложении. Расчет исправлен: используются исходные суммы и неокругленные веса, округляется вывод. Финальный полный прогон после исправления успешен.

Большой воспроизводимый набор: 10 000 кредитов, 12 месячных срезов, 120 000 записей snapshots. Это фиксированная синтетическая когорта, а не реальные клиенты. Результаты не подтверждают качество реальной модели кредитного риска.

## HTTP и пользовательский сценарий

Настоящий Uvicorn слушал `127.0.0.1:8000`. Скрипт `python -m scripts.smoke` проверил `/api/health`, `/api/ready`, `/api/context`, `/api/dashboard`, затем `/api/chat`. Сценарий DEMO вернул отчет и три успешных MCP-вызова. Это реальные локальные HTTP-запросы, не TestClient и не подмененные результаты.

Отдельно проверена поставка из распакованного ZIP без заранее созданной базы: при первом запуске генерируются данные, открывается UI и презентация, выполняется сквозной сценарий. Машиночитаемый результат — [`examples/release-check.json`](examples/release-check.json).

## Браузерная проверка: важная граница

Среда Chromium блокировала прямой переход на локальный HTTP адрес (`ERR_BLOCKED_BY_ADMINISTRATOR`). Поэтому использовался режим `scripts.ui_smoke --bridge`:

- HTML/CSS/JS приложения загружались из файлов поставки без изменения бизнес-логики.
- `fetch` передавался через Playwright bridge в `httpx`, который обращался к **настоящему локальному HTTP API**, MCP-процессу и SQLite. Аналитические ответы не подменялись.
- Проверялись отображение данных, сценарий атрибуции, раскрытие `[Tn]`, фильтр продукта, события скачивания всех трех экспортов, мобильная ширина и интерактивность HTML-слайдов.

Результат: ошибок JavaScript нет; источники раскрываются; фильтр «Потребительский» показывает 4096 кредитов; события скачивания `riskinsight-dashboard.json`, `riskinsight-report.md`, `riskinsight-evidence.json` получены; горизонтального переполнения при 390×844 нет. Слайды реагируют на стрелки, выбор узла архитектуры и изменение даты. Снимки лежат в [`screenshots/`](screenshots/).

Это **не** проверка нативной браузерной сети, CSP, TLS, длительного LLM-запроса через прокси или публичного хостинга. Содержимое всех экспортов не подвергалось отдельной побайтовой проверке. Перед защитой повторите обычный браузерный запуск без `--bridge` на опубликованном сервисе.

## Что не было выполнено

| Проверка | Статус и причина |
|---|---|
| Реальный ответ внешней/локальной LLM | Не выполнена: не предоставлены ключ, модель или работающий локальный endpoint. Подготовлен `scripts.check_llm`; unit-тесты провайдера используют HTTP mock. |
| Независимый официальный MCP SDK / Inspector | Не выполнена: SDK отсутствует, его установка была недоступна из среды. Подготовлены `requirements-sdk.txt` и `scripts.sdk_smoke`. Встроенный клиент и сервер реально обменивались JSON-RPC. |
| Docker build и запуск контейнера | Не выполнены: нет Docker CLI/daemon. Поставлены Dockerfile и Compose; их нужно проверить перед хостингом. |
| Публичный GitHub, GitHub Actions, HTTPS-хостинг | Не выполнены: аккаунты публикации не подключены. Не заявляется существующий публичный URL. |
| Нагрузочный тест, пентест, аудит защиты, настоящие банковские данные | В объем MVP не входят; промышленная готовность не заявляется. |
| Полная верификация всех чисел в ответе модели | Не реализована. Проверяются существование ссылок и расчетные инструменты, но не семантическая истинность произвольного текста LLM. |

## Как повторить

Из корня проекта:

```bash
pip install -r requirements-dev.txt
python -m compileall -q app scripts
python -m pytest -q --junitxml=test-results.xml
```

В отдельном терминале запустите приложение, затем:

```bash
python -m scripts.smoke
pip install -r requirements-ui.txt
python -m playwright install chromium
python -m scripts.ui_smoke
```

Браузерный скрипт рассчитан на локальный запуск без APP_ACCESS_TOKEN. Для сетево-ограниченной тестовой среды предусмотрен `--bridge`, но он не заменяет обычную приемку.

Независимая проверка MCP:

```bash
pip install -r requirements-sdk.txt
python -m scripts.seed
python -m scripts.sdk_smoke
```

После настройки `APP_MODE=llm`, `LLM_API_KEY`, `LLM_MODEL`:

```bash
python -m scripts.check_llm
```

Последняя команда действительно обращается к выбранной модели и может расходовать платные токены. Не передавайте ключи через аргументы командной строки и не публикуйте `.env`.
